# Tic Tac Toe 🎮

A simple and interactive **Tic Tac Toe game** built using **React.js**.  
This project demonstrates the use of React components, state management, and basic game logic.

---

## 🌐 Live Demo

👉 **Play the game here:**  
https://subham0023.github.io/Tic-Tac-Toe/

---

## 📌 Features

- Two-player game (X vs O)
- Displays winner or draw result
- Prevents overwriting filled cells
- Option to restart the game
- Clean and user-friendly UI

---

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6)
- HTML5
- CSS3
